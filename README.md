# BCE Vereinsnews

Dateien für die E-Mail-Newsletter des Basketball Club Erfurt e.V.

* `assets/` Bilder und Kalenderdateien, die die Mails öffentlich laden. Dateien hier nicht umbenennen oder löschen, solange verschickte Mails darauf verweisen.
* `ausgaben/` fertige Versanddateien je Ausgabe. Datei in Chrome öffnen, alles markieren, kopieren und in Gmail einfügen.
* `werkzeug/` `build.py` erzeugt die Mails, `qa.py` prüft sie.

Das Repository muss öffentlich bleiben, sonst sehen die Empfänger keine Bilder.
